# HUFS BUS Beta APK

베타테스트용 Android 설치 파일입니다.

- 파일: `HUFS-BUS-beta-debug.apk`
- 용도: 팀원 실기기 설치 및 기능 테스트
- 기준 브랜치: `fe/api-integration`

설치 방법:

1. GitHub에서 `HUFS-BUS-beta-debug.apk` 파일을 다운로드합니다.
2. Android 기기로 파일을 옮깁니다.
3. 파일을 열어 설치합니다.
4. 설치 차단 안내가 뜨면, 테스트 기기에서 해당 파일 관리 앱의 `알 수 없는 앱 설치` 권한을 허용합니다.

주의:

- 이 APK는 베타테스트용 debug 빌드입니다.
- Play Store 배포용 release APK는 별도 서명 키 설정이 필요합니다.
